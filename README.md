# 坦克大战 (Tank Battle)

一个纯 HTML + Canvas + JavaScript 实现的经典坦克大战小游戏，单文件即可运行，无需任何依赖。

## 🎮 玩法

- **移动**：`W` `A` `S` `D` 或方向键 `↑` `←` `↓` `→`
- **发射**：`空格`
- **暂停**：`P`

## ✨ 特性

- 经典的地图障碍物：砖墙（可摧毁）、钢墙（不可摧毁）、水面、草丛
- 敌方 AI 坦克会自动移动并朝玩家射击
- 多关卡：每通关一次难度提升，敌人数量与速度增加
- 计分、生命值、关卡显示
- 粒子爆炸特效
- 响应式 HUD

## 🚀 运行

直接用浏览器打开 `index.html` 即可开始游戏。

或者在本地启动一个 HTTP 服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```
